## Getting Started

Node.js와 npm이 설치되어 있어야 합니다.

```bash
npm install
npm run dev
```

개발 서버 주소는 터미널에 표시되는 Vite 주소(보통 `http://localhost:5173`)를 사용합니다.

프로덕션 빌드:

```bash
npm run build
npm run preview
```

위 명령어는 기본적인 Vite 프로젝트를 전제로 합니다. 실제 `package.json`의 스크립트를 확인하세요.
